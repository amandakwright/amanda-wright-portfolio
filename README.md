# Amanda Wright portfolio: static site

Plain HTML + CSS, no build step and no JavaScript. Open `index.html` in a browser to preview, or upload this whole folder to any static host (Netlify, GitHub Pages, Vercel, Cloudflare Pages, or a Webflow/Squarespace-free host).

- `index.html`: homepage
- `work.html`: full work grid
- `about.html`: about page
- `children-hospital-of-philadelphia.html`, `sutter-health.html`: skeleton case studies (bracketed placeholder text + dashed image boxes still to fill)
- `tufts-medicine.html`, `michigan-medicine.html`, `medical-laboratory.html`, `head-to-toe.html`: finished case studies
- `styles.css`: shared styles (fonts load from Google Fonts)
- `images/`: every image used on the site
